# AI Assistant

AI-ассистент, который автоматически отвечает на входящие сообщения в личном Telegram-аккаунте.

Проект работает через Hydrogram, отправляет сообщения в DeepSeek API, сохраняет историю каждого диалога в Redis и умеет распознавать голосовые сообщения с помощью Faster Whisper.

## Возможности

* автоматические ответы на входящие личные сообщения;
* работа от имени Telegram-аккаунта;
* поддержка текстовых сообщений;
* распознавание голосовых сообщений;
* отдельная история для каждого диалога;
* хранение контекста в Redis;
* генерация ответов через DeepSeek API;
* настройка стиля общения через системный промпт;
* запуск через Docker Compose.

## Стек

* Python 3.13
* Hydrogram
* LangChain
* DeepSeek API
* Redis
* Faster Whisper
* Docker

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/aurusxd/ai-assistant.git
cd ai-assistant
```

Создайте файл `.env`:

```env
DEEPSEEK_API_KEY=your_deepseek_api_key

API_ID=your_telegram_api_id
API_HASH=your_telegram_api_hash

REDIS_URL=redis://redis:6379/0
```

`API_ID` и `API_HASH` можно получить в кабинете Telegram API.

## Запуск через Docker

```bash
docker compose up --build
```

При первом запуске Hydrogram запросит:

1. номер телефона Telegram;
2. код подтверждения;
3. пароль двухфакторной аутентификации, если он включён.

После авторизации Telegram-сессия будет сохранена и повторный вход не потребуется.

## Локальный запуск

Установите зависимости через `uv`:

```bash
uv sync
```

Запустите Redis и укажите адрес подключения:

```env
REDIS_URL=redis://localhost:6379/0
```

Запустите приложение:

```bash
uv run python main.py
```

## Как это работает

1. Hydrogram получает входящее сообщение.
2. Если сообщение голосовое, Faster Whisper преобразует его в текст.
3. История переписки загружается из Redis.
4. Сообщение и контекст передаются в DeepSeek.
5. Сгенерированный ответ отправляется в Telegram.
6. История диалога сохраняется отдельно для каждого пользователя.

## Настройка поведения

Стиль ответов задаётся переменной `SYSTEM_PROMPT` в файле:

```text
services/llm_service.py
```

Изменив промпт, можно настроить:

* длину сообщений;
* стиль общения;
* использование сленга;
* поведение ассистента;
* правила продолжения диалога.

## Ограничения

* ассистент отвечает только в личных чатах;
* сообщения от ботов игнорируются;
* поддерживаются текстовые и голосовые сообщения;
* максимальная длительность голосового сообщения — 3 минуты;
* история диалога хранится в Redis 1 час.
