# AI Assistant

AI-ассистент, который автоматически отвечает на входящие сообщения в личном Telegram-аккаунте.

Проект работает через Hydrogram, отправляет сообщения в DeepSeek API, сохраняет историю каждого диалога в Redis и умеет распознавать голосовые сообщения с помощью Faster Whisper.

## Возможности

* автоматические ответы на входящие личные сообщения;
* работа от имени Telegram-аккаунта;
* поддержка текстовых сообщений;
* распознавание голосовых сообщений;
* отдельная история для каждого диалога;
* хранение контекста в Redis;
* генерация ответов через DeepSeek API;
* настройка стиля общения через системный промпт;
* бот управления: включение/выключение, смена промпта, задержки, креативности, списков собеседников прямо из Telegram;
* запуск через Docker Compose.

## Стек

* Python 3.13
* Hydrogram
* LangChain
* DeepSeek API
* Redis
* Faster Whisper
* Docker

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/aurusxd/ai-assistant.git
cd ai-assistant
```

Создайте файл `.env`:

```env
DEEPSEEK_API_KEY=your_deepseek_api_key

API_ID=your_telegram_api_id
API_HASH=your_telegram_api_hash

REDIS_URL=redis://redis:6379/0

# Бот управления (необязательно)
BOT_TOKEN=your_bot_token
ADMIN_IDS=
```

`API_ID` и `API_HASH` можно получить в кабинете Telegram API.

`BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather). Если не задан, приложение работает как раньше, без бота управления.

`ADMIN_IDS` — id дополнительных людей через запятую, которым можно управлять ботом. Владелец аккаунта, от имени которого работает ассистент, получает доступ автоматически.

## Запуск через Docker

```bash
docker compose up --build
```

При первом запуске Hydrogram запросит:

1. номер телефона Telegram;
2. код подтверждения;
3. пароль двухфакторной аутентификации, если он включён.

После авторизации Telegram-сессия будет сохранена и повторный вход не потребуется.

## Локальный запуск

Установите зависимости через `uv`:

```bash
uv sync
```

Запустите Redis и укажите адрес подключения:

```env
REDIS_URL=redis://localhost:6379/0
```

Запустите приложение:

```bash
uv run python main.py
```

## Как это работает

1. Hydrogram получает входящее сообщение.
2. Если сообщение голосовое, Faster Whisper преобразует его в текст.
3. История переписки загружается из Redis.
4. Сообщение и контекст передаются в DeepSeek.
5. Сгенерированный ответ отправляется в Telegram.
6. История диалога сохраняется отдельно для каждого пользователя.

## Бот управления

Напиши своему боту `/start` — откроется панель:

* 🟢/🔴 включить или выключить автоответы;
* 📝 посмотреть, изменить или сбросить к стандартному промпт — то, как программа общается за тебя (длинный промпт можно прислать `.txt` файлом);
* ⏱ задержка перед отправкой ответа;
* 🌡 креативность (temperature) модели;
* 🎙 включить или выключить распознавание голосовых;
* 👥 чёрный и белый списки и режим «отвечать всем» / «только белому списку»;
* 🧹 сбросить историю всех диалогов или одного чата.

Команды (их можно добавить в меню бота через @BotFather → Edit Commands):

```text
menu - панель управления
on - включить автоответы
off - выключить автоответы
prompt - показать или задать промпт
ignore - не отвечать человеку
unignore - убрать из чёрного списка
allow - добавить в белый список
disallow - убрать из белого списка
reset - сбросить историю диалога
cancel - отменить ввод
help - список команд
```

Людей можно указывать по `@username` или числовому id. Настройки хранятся в Redis и применяются сразу, без перезапуска.

## Настройка поведения

Стиль ответов задаётся промптом, который меняется через бота управления. Стандартный промпт (`DEFAULT_SYSTEM_PROMPT`) лежит в файле:

```text
services/settings_service.py
```

Изменив промпт, можно настроить:

* длину сообщений;
* стиль общения;
* использование сленга;
* поведение ассистента;
* правила продолжения диалога.

## Ограничения

* ассистент отвечает только в личных чатах;
* бот управления отвечает только владельцу аккаунта и `ADMIN_IDS`;
* сообщения от ботов игнорируются;
* поддерживаются текстовые и голосовые сообщения;
* максимальная длительность голосового сообщения — 3 минуты;
* история диалога хранится в Redis 1 час.
